# Home Assistant App: Consequences

![Supports aarch64][aarch64] ![Supports amd64][amd64] ![Supports armv7][armv7]

The classic folded-paper party game, online. Write a bit, fold it, pass it on, then unfold the chaos. You can draw the people, outfits and places too. Many rooms at once, any browser, any device. Works through your Cloudflare Tunnel so family and friends anywhere can join.
